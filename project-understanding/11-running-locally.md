# 11 — Running locally

## Prerequisites

- **Docker Desktop** (Compose v2) — runs all three services
- **Node 18+** on the host — only for the editor and the E2E suite
- **An OpenAI-compatible API key** — nothing extracts without one

## First run

```bash
git clone <repo> && cd krupali-project-personal
make up
```

`make up` runs `make setup` first, which:

1. copies `.env.example` → `.env` if it does not exist,
2. generates a random `JWT_SECRET` if it is still `changeme`,
3. creates `backend/uploads/` with write permissions.

Then it builds and starts the three containers. The backend runs
`alembic upgrade head` before Uvicorn, so the schema is migrated automatically.

**Then edit `.env` and set a real `LLM_API_KEY`.** Everything else has a working
default; this one does not.

```bash
# .env — the OpenAI configuration this project is tuned for
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL=gpt-4o-mini
LLM_API_KEY=sk-...
```

`docker compose restart backend` after changing it.

## For the editor

```bash
cd frontend && npm install
```

The container keeps its own `node_modules` in an anonymous volume, so a package
installed there is **absent from the host** and the editor's TypeScript server
cannot resolve it — which looks like every line of every file being wrong. Run this
after any pull that touches `frontend/package.json`. Full explanation in
`docs/VSCODE_SETUP.md`.

## Environment variables

| Variable | Default | What it does |
|---|---|---|
| `LLM_API_KEY` | — | **Required.** No extraction without it |
| `LLM_BASE_URL` | NVIDIA NIM in the example | Any OpenAI-compatible endpoint |
| `LLM_MODEL` | — | `gpt-4o-mini` is what the tuning assumes |
| `DATABASE_URL` | compose value | Postgres connection |
| `JWT_SECRET` | generated by `make setup` | Signs tokens. Rotating it invalidates every session |
| `JWT_EXPIRE_MINUTES` | 480 | Session length |
| `EXTRACTION_RPS` | 1.3 | Calls per second. **Raising this above the account's real limit makes processing slower, not faster** |
| `EXTRACTION_CONCURRENCY` | 16 | Calls in flight |
| `MAX_UPLOAD_MB` | 25 | Upload ceiling |
| `LOGIN_MAX_ATTEMPTS` | 10 | Per address per window |
| `LOGIN_WINDOW_SECONDS` | 900 | |
| `REGISTER_MAX_ATTEMPTS` | 5 | Per IP per window |
| `REGISTER_WINDOW_SECONDS` | 3600 | |
| `VITE_API_URL` | `http://localhost:8002` | Where the browser calls the API |
| `VITE_API_URL_ORIGIN` | `http://localhost:3002` | The single allowed CORS origin |

## Make targets

```
make up        build and start everything (runs setup first)
make down      stop and remove containers
make build     rebuild images
make logs      tail all services
make migrate   alembic upgrade head
make test      backend pytest suite
make e2e       start the stack with raised auth limits, then run Playwright
make clean     down -v --rmi local  (destroys the database volume)
make restart   down then up
```

## A first walk-through

1. http://localhost:3002 → **Get started** → register.
2. **Upload document** → pick anything from `samples/` — six realistic aged-care
   policies, 24–35 pages each.
3. The card shows *Queued* → *Reading* → *Ready*, updating on its own.
4. Open it. Summary, Obligations, Risks, Deadlines, Actions, Sections.
5. Ask the assistant *"What deadlines are mentioned?"* — the answer cites sections;
   clicking a citation jumps to the text.
6. **Evaluation results** → the self-check runs on its own.

To see the relevance gate refuse something, upload
`frontend/e2e/fixtures/office-supplies-invoice.pdf`.

## Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| Every document ends `failed` or findings are empty | `LLM_API_KEY` unset or wrong | Set it in `.env`, `docker compose restart backend` |
| `429` on register/login while testing | The rate limits, working | Wait, or `LOGIN_MAX_ATTEMPTS=1000 REGISTER_MAX_ATTEMPTS=1000 docker compose up -d` |
| Red underlines on every line in VS Code | Host `node_modules` is stale | `cd frontend && npm install`, then *TypeScript: Restart TS Server* |
| Extraction very slow / lots of 429s in the log | `EXTRACTION_RPS` above the account's limit | Lower it |
| Frontend loads, every request fails | Backend not up, or `VITE_API_URL` wrong | `docker compose ps`, check `/health` |
| `Document not found` on your own document | A stale token from before a `JWT_SECRET` change | Sign out and back in |
| Port already in use | 3002 / 8002 / 5434 taken | Change the mapping in `docker-compose.yml` |
| Schema errors after pulling | New migration | `make migrate` |

```bash

docker compose exec backend python -m pytest tests -q

# What did extraction actually produce?
docker compose exec backend python -c "
from app.database import SessionLocal

db = SessionLocal()
for d in db.query(Document).all():
    print(d.id, d.status, d.filename[:40],
          'sec', db.query(Section).filter_by(document_id=d.id).count(),
```
